# Infrastructure-as-Code

Infrastructure-as-Code (IaC) is the practice of provisioning and managing servers, networks, and cloud resources through declarative code rather than manual configuration — a recurring line item in Kyle's enterprise-software research. He flagged it in his Roam **Deep Dives** both as its own topic and as one of the four named "Trends" on the Enterprise Software — Deep Dive page (alongside Containers/Kubernetes/Microservices, Hyperautomation, and Conversational Intelligence).

It sits inside the broader [Infrastructure](/notes/infrastructure) and [DevOps](/notes/devops) tooling stack — the automation layer that lets teams treat their environments the way they treat application code (versioned, reviewable, reproducible).
