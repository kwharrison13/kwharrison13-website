# Danny Hillis

Credited (via an editorial correction in the text) as the actual source of the line "technology is the set of things that don't quite work yet" — the book initially attributes it to [Alan Kay](/notes/alan-kay) before flagging Hillis as the correct originator. [Naval Ravikant](/notes/naval-ravikant) uses the quote to argue that once something works reliably it's no longer "technology," it's just infrastructure society expects. No other detail on Hillis is given in the source.
