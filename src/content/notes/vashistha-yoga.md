# Vashistha Yoga

Named only in a passing update-note in [Naval Ravikant](/notes/naval-ravikant)'s recommended-reading list inside [The Almanack of Naval Ravikant](/books/the-almanack-of-naval-ravikant). Ravikant describes himself as "pretty much always rereading something by either Jiddu Krishnamurti or [Osho](/notes/osho)," then adds a bracketed update: "I'd now add [Jed McKenna](/notes/jed-mckenna), [Kapil Gupta](/notes/kapil-gupta), the Vashistha Yoga, and Schopenhauer to that list." The book gives no further description of the text itself.
